The Router Confesses: **"I didn't drop the connection; I took a dramatic pause at the climax. The movie needed tension. You needed Wi-Fi. We can't both win."** (131 characters).

One line in which a home Wi-Fi router excuses itself for dropping the connection at the exact moment a movie reaches its climax: it did not drop anything — it took a dramatic pause. The movie needed tension, the viewer needed Wi-Fi, and they cannot both win. The excuse is in the router's own smug voice, it dodges the obvious buffering, bandwidth and firmware-update jokes, and the punchline lands in the last words. A judge model reads two excuses at a time and keeps the funnier one, round after round. The other candidates considered are kept in `vA/`, `vB/`, `vC/` with their reasoning in `NOTES.md`.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (the grader runs Node 22.23.4). The program writes exactly the entry text to `/output/entry.txt` — no trailing newline — and prints exactly that text to stdout. It uses no network, no randomness, no clock and no environment input, so two runs produce byte-identical output.
